# Project overview
- Unity project migrated from an older Unity 2017-era Pixel Gun/PGXI codebase to Unity Editor 6000.4.10f1.
- Root contains Unity folders: `Assets`, `Packages`, `ProjectSettings`, plus generated `Library`, `Temp`, `Logs`, and C# solution/project files.
- Scripts are mostly under `Assets/Scripts/Assembly-CSharp` and legacy/decompiled UnityScript-era converted C# under `Assets/Scripts/Assembly-UnityScript`.
- README is minimal (`# 11.3.1-but-good`).
- Package manifest uses Unity packages including ads, analytics, purchasing, test-framework, timeline, ugui, AI navigation, and legacy input helpers.
